# Browser QA

Use this skill only when repository changes include rendered documentation, diagrams, or a frontend workflow.

## Instructions

- Prefer local documentation checks when the change is Markdown-only.
- For generated docs sites, verify navigation, images, anchors, and mobile layout.
- For any future cluster-request frontend, test the actual request workflow that writes cluster inventory YAML.
- Confirm examples do not display real credentials or internal endpoints unless intentionally sanitized.

## Reporting

Report browser/device coverage and any skipped checks.
